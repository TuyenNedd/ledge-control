# Settings UI, onboarding, and build tooling for Ledge (v2)

Adds a SwiftUI Settings window (three tabs: Gesture, Behavior, About) hosted via NSHostingController, a three-page first-launch onboarding flow with live Accessibility polling and step-count feedback, menu bar icon tint highlight during gestures, a configurable codesigning identity with certificate guide, and a `make reinstall` target. The fix commit (c7b2ea5) addressed four of five concerns from the v1 review: timer leak resolved via `Timer.publish` + `.onReceive`, double view-tree construction eliminated by an `@Observable` coordinator, slider-per-frame `applyPreferences()` guarded by `isEditingSlider` + `onEditingChanged`, and onboarding ordering fixed to start the tap before showing the window. The single-slot callback was intentionally retained. Watch for: no new blocking concerns identified in this pass.

**Verdict**: APPROVED

## High-level view

All four previously-flagged blocking issues are resolved. The timer fix uses `Timer.publish` with `.autoconnect()` paired with `.onReceive` on per-page views, so SwiftUI's subscription lifecycle handles cancellation when the window closes. The slider debounce splits correctly: `didSet` always writes to `Preferences` (keeping the preview live), but `applyPreferencesClosure()` is gated behind `!isEditingSlider` and fires on drag-end via `onEditingChanged`. The coordinator pattern and the start-before-onboarding reorder are both straightforward and correct.
